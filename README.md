# ru-name-anonymizer

Анонимизация русских имён, отчеств и фамилий в тексте. Чистый Python, без ML-моделей и внешних зависимостей: словарь имён лежит в пакете, отчества и фамилии распознаются по суффиксам.

```python
from ru_name_anonymizer import anonymize_names

anonymize_names("Позвони Александру Сергеевичу Петрову")
# 'Позвони Павлу Андреевичу Орлову'
```

Замена сохраняет род и падеж: «Диме» → «Ивану», «Марии Ивановне» → «Ольге Михайловне».

## Функции

| Функция | Что делает |
|---|---|
| `anonymize_names(text, rng=None, aggressive=False, languages=("ru",), kinds=все, replace=None)` | Каждое вхождение имени заменяется независимо |
| `anonymize_names_consistent(text, rng=None, aggressive=False, languages=("ru",), kinds=все, replace=None)` | Одно и то же имя, отчество или фамилия всегда получает одну замену; разные — разные |
| `find_names(text, aggressive=False, languages=("ru",), kinds=все)` | Находит имена с позициями, ничего не заменяя |
| `Anonymizer(...)` | Настройки задаются один раз; согласованные замены между вызовами — см. [Встраивание в приложение](#встраивание-в-приложение) |
| `preload(languages=("ru",), kinds=все)` | Загружает словарь заранее |

`aggressive=True` заменяет «вообще всё»: имена в нижнем регистре и КАПСЕ («дима», «ДИМА»), одиночные фамилии («сказал Иванов») и имена, совпадающие с обычными словами («Надежда», «Любовь», «Роман»). В этом режиме возможны ложные срабатывания на обычных словах и городах («Ростов»).

Формы одного имени («Дмитрий» и «Дима») считаются разными людьми и получают разные замены.

## Языки

Параметр `languages` выбирает, какие словари использовать: `"ru"` (по умолчанию), `"en"` или оба.

```python
anonymize_names("Иван Петров и John Smith", languages="ru")           # заменит только русские
anonymize_names("Иван Петров и John Smith", languages="en")           # только английские
anonymize_names("Иван Петров и John Smith", languages=("ru", "en"))   # и те и другие
```

Имя заменяется именем того же языка и рода. Английский словарь небольшой (самые популярные имена и фамилии, около 70 имён и 50 фамилий), хранится прямо в коде и не склоняется: «John's» → «David's». Работают инициалы («J. K. Smith»), фамилия без имени рядом заменяется только в `aggressive`. Неоднозначные имена («Will», «Mark», «Hope», «May») заменяются только в `aggressive` и только с заглавной буквы. Если русский не выбран, русский словарь не загружается.

## Что заменять

Параметр `kinds` включает и выключает каждый источник отдельно:

| Вид | Чем находится |
|---|---|
| `"first"` | имена по словарю лемм (русскому и/или английскому) |
| `"patronymic"` | отчества по суффиксам `-ович/-овна` |
| `"surname"` | фамилии по суффиксам `-ов/-ин/-ский` и английскому списку |
| `"initials"` | инициалы («И. И.», «J. K.») |

```python
anonymize_names(text, kinds="first")                        # только имена
anonymize_names(text, kinds=("patronymic", "surname"))      # без словаря лемм
anonymize_names(text, kinds=("first", "initials"), languages=("ru", "en"))
```

Отключённый источник не используется вообще: без `"first"` русский словарь не загружается (экономия ≈0,3 с и ≈5 МБ), а фамилии заменяются и без имени рядом, потому что опереться на имя нельзя. Остальные виды работают независимо друг от друга. Инициалы без фамилии рядом заменяются, только если букв две («А. С.»): одиночная «Б.» в «пункт Б.» остаётся как есть.

## Встраивание в приложение

**Найти, не заменяя.** `find_names` возвращает список `NameEntity` в порядке появления в тексте; находится ровно то, что заменила бы `anonymize_names` с теми же параметрами:

```python
from ru_name_anonymizer import find_names

find_names("Позвони Александру Сергеевичу Петрову")
# [NameEntity(start=8, end=18, text='Александру', kind='first', normal_form='Александр',
#             gender='m', case='datv', language='ru'),
#  NameEntity(..., text='Сергеевичу', kind='patronymic', normal_form='Сергеевич', ...),
#  NameEntity(..., text='Петрову', kind='surname', normal_form='Петров', ...)]
```

| Поле | Значение |
|---|---|
| `start`, `end` | позиции в исходном тексте: `text[start:end] == entity.text` |
| `kind` | `"first"`, `"patronymic"`, `"surname"`, `"initials"` |
| `normal_form` | начальная форма: «Петровой» → «Петрова», «Достоевского» → «Достоевский»; для инициалов — сам текст |
| `gender` | `"m"`, `"f"` или `"c"` (не определён) |
| `case` | падеж (`"nomn"`, `"gent"`, `"datv"`, `"accs"`, `"ablt"`, `"loct"`); у инициалов `None` |
| `language` | `"ru"` или `"en"` |

**Своя замена.** `replace` получает `NameEntity` и возвращает строку (подставляется как есть, без подгонки регистра) или `None` — тогда используется стандартная случайная замена:

```python
anonymize_names(text, replace=lambda e: "[ФИО]")                                  # маска
anonymize_names(text, replace=lambda e: "[ФАМИЛИЯ]" if e.kind == "surname" else None)
```

**Настроить один раз.** `Anonymizer` принимает те же параметры (`rng`, `aggressive`, `languages`, `kinds`, `replace`) и `consistent`. С `consistent=True` одно и то же имя получает одну замену во всех вызовах объекта — удобно, когда документ, чат или датасет обрабатывается по частям:

```python
from ru_name_anonymizer import Anonymizer

anon = Anonymizer(consistent=True)
anon.anonymize("Иван пришёл.")   # 'Леонид пришёл.'
anon.anonymize("Ивана нет.")     # 'Леонида нет.'
anon.reset()                     # забыть накопленные замены
```

`anonymize_detailed(text)` возвращает `AnonymizeResult(text, replacements)`, где каждая `Replacement` — пара «найденная сущность → подстановка»: по ней можно вести аудит или восстановить исходный текст. `find(text)` и `preload()` работают как одноимённые функции. В режиме `consistent` объект хранит состояние, поэтому не вызывайте один экземпляр из нескольких потоков одновременно; без `consistent` он состояния не хранит.

Пакет типизирован (`py.typed`).

## Как это работает

- **Имена** ищутся по словарю лемм (≈12,5 тыс. имён). Падежи строятся правилами склонения, а нерегулярные имена («Павел» → «Павла») хранятся в словаре явно. Слова, которые чаще бывают обычными существительными («Вера», «Мир», «Март»), в словарь не входят.
- **Отчества** — по суффиксам `-ович/-евич`, `-овна/-евна` в любом падеже.
- **Фамилии** (`-ов/-ев/-ин/-ын`) заменяются только рядом с найденным именем или отчеством, чтобы не трогать обычные слова.
- Имена, уже встретившиеся в тексте, не выбираются в качестве замены.
- Из коробки понимаются инициалы («Иванов И.И.», «И. И. Иванов», «А.С.Пушкин»), фамилии на -ский/-цкий (кроме прилагательных вроде «Технический», «Российский»), составные имена через дефис («Жан-Люк») и имена-омонимы вроде «Света», «Вера» (с заглавной буквы). Одиночное имя-омоним в начале фразы («Света не было», «Нате, держите») не заменяется, если в тексте оно больше нигде не встречается как имя.
- Английские фамилии, совпадающие с обычными словами («White», «Young», «Green»), без имени или инициалов рядом не заменяются даже в `aggressive`.
- Слова разбираются с кэшем, текст обрабатывается за один проход: 66 тыс. символов — около 40 мс (около 90 мс в `aggressive`).

## Установка

```bash
pip install git+https://github.com/HACER777BEBRA/ru-name-anonymizer
```

Словарь (≈0,3 МБ) загружается при первом вызове за ≈0,3 с и занимает ≈5 МБ памяти. Чтобы не ждать в первом запросе, вызовите `ru_name_anonymizer.preload()` при старте приложения.

Для воспроизводимых замен передайте `random.Random`: `anonymize_names(text, rng=random.Random(0))`.

## Ограничения

- По умолчанию распознаются только слова с заглавной буквы, неоднозначные имена («Надежда», «Роман») и одиночные фамилии не заменяются; всё это включает `aggressive=True`.
- Фамилии на `-ский/-цкий` и иностранные фамилии без имени рядом не трогаются.
- Это инструмент для debug-логов и тестовых данных, а не гарантия полной обезличенности.

## Разработка

```bash
pip install -e ".[dev]"
ruff check . && pytest
```

Словарь `src/ru_name_anonymizer/names.txt` — обычный текст: строка `Анна f` для имён с регулярным склонением и `Павел m Павла Павлу Павла Павлом Павле` для исключений. Пересобирается скриптом `tools/build_names.py` (нужны `pymorphy2==0.9.1`, `pymorphy2-dicts-ru`, `setuptools<81`; только для сборки, в рантайме не нужны); скрипт сверяет результат правил с pymorphy2 по всем именам.
