# ru-name-anonymizer

Анонимизация русских (и английских) имён, отчеств и фамилий в тексте, а также ников и других идентификаторов, которые приложение передаёт во время работы. Чистый Python без ML-моделей и внешних зависимостей: словарь имён лежит в пакете, отчества и фамилии распознаются по суффиксам.

```python
from ru_name_anonymizer import anonymize_names

anonymize_names("Позвони Александру Сергеевичу Петрову")
# 'Позвони Павлу Андреевичу Орлову'
```

Замена сохраняет род и падеж: «Диме» → «Ивану», «Марии Ивановне» → «Ольге Михайловне».

## Установка

```bash
pip install git+https://github.com/HACER777BEBRA/ru-name-anonymizer
```

## Функции

| Функция | Что делает |
|---|---|
| `anonymize_names(text, rng=None, aggressive=False, languages=("ru",), kinds=все, replace=None, exclude=None, pools=None, dynamic=None, auto_detect=False)` | Каждое вхождение заменяется независимо |
| `anonymize_names_consistent(...)` | Одно и то же имя всегда получает одну замену, разные — разные |
| `find_names(text, aggressive=False, languages=("ru",), kinds=все, exclude=None, dynamic=None, auto_detect=False)` | Находит имена с позициями, ничего не заменяя |
| `Anonymizer(...)` | Настройки один раз, согласованность между вызовами, сохранение состояния |
| `inflect(name, case, kind="first", gender=None, language=None)` | Ставит имя, отчество или фамилию в нужный падеж |
| `preload(languages=("ru",), kinds=все)` | Загружает словарь заранее |
| `available_languages()`, `register_locale(locale)` | Список языков и подключение своего (см. «Свой язык») |
| `available_dynamic()`, `register_dynamic_locale(locale)` | Список динамических локалей и подключение своей (см. «Динамические локали: ники») |

Для воспроизводимых замен передайте `rng=random.Random(0)`. Пакет типизирован (`py.typed`).

## Параметры

**`languages`** — `"ru"` (по умолчанию), `"en"` или несколько, например `("ru", "en")`. Имя заменяется именем того же языка и рода. Если слово записано буквами, общими для нескольких языков, его разбирает первый в списке язык, который его узнал. Английский словарь небольшой (≈70 имён и 50 фамилий) и не склоняется: «John's» → «David's».

**`kinds`** — что заменять:

| Вид | Чем находится |
|---|---|
| `"first"` | имена по словарю лемм |
| `"patronymic"` | отчества по суффиксам `-ович/-овна` |
| `"surname"` | фамилии по суффиксам `-ов/-ин/-ский` и английскому списку |
| `"initials"` | инициалы («И. И.», «J. K.») |
| `"nickname"` | термины динамических локалей: ники, username (см. «Динамические локали: ники») |

Без `"first"` фамилии заменяются и без имени рядом, ведь опереться на имя нельзя. Одиночные инициалы заменяются, только если букв две («А. С.»), — «пункт Б.» остаётся как есть.

**`aggressive`** — `True` заменяет «вообще всё», либо можно включить части:

| Часть | Что добавляет |
|---|---|
| `"any_case"` | имена в нижнем регистре и КАПСЕ («дима», «ДИМА») |
| `"lone_surnames"` | фамилии без имени рядом («сказал Иванов», «Smith said») |
| `"ambiguous"` | имена-омонимы («Надежда», «Роман», «Will») и омонимы в начале фразы («Света не было») |

```python
anonymize_names(text, aggressive=("any_case", "ambiguous"))
```

Омонимы в нижнем регистре («много света») заменяются только при обеих частях `any_case` и `ambiguous`. С `aggressive` возможны ложные срабатывания («Ростов»), их убирает `exclude`.

**`exclude`** — слова, которые не трогать. Сравниваются без учёта регистра по самому слову и начальной форме, так что исключаются все падежи и оба рода фамилии:

```python
anonymize_names("Иван Ростов приехал в Ростове", aggressive=True, exclude=["Ростов"])
# 'Леонид Ростов приехал в Ростове'
```

**`pools`** — свои списки замен в именительном падеже, склонение подберётся само. Не заданные ключи берутся из стандартных пулов, неподходящие значения («Шевченко», косвенный падеж) сразу дают `ValueError`:

```python
pools = {"first_m": ["Акакий", "Jack"], "first_f": ["Нинель"],
         "patronymic": ["Тихонович"], "surname": ["Пушкин", "Вяземская"]}
anonymize_names("Позвони Ивану Сергеевичу Петрову и Марии Ивановне Достоевской", pools=pools)
# 'Позвони Акакию Тихоновичу Пушкину и Нинели Тихоновне Вяземской'
```

**`replace`** — своя функция: получает `NameEntity`, возвращает строку (подставляется как есть) или `None` для стандартной замены:

```python
anonymize_names(text, replace=lambda e: "[ФИО]")
anonymize_names(text, replace=lambda e: "[ФАМИЛИЯ]" if e.kind == "surname" else None)

# замены из своей базы со склонением
fakes = {"Иван": "Павел"}
anonymize_names(text, kinds="first",
                replace=lambda e: inflect(fakes[e.normal_form], e.case, gender=e.gender))
```

## Поиск без замены

`find_names` возвращает список `NameEntity` в порядке появления — ровно то, что заменила бы `anonymize_names` с теми же параметрами:

```python
find_names("Позвони Александру Сергеевичу Петрову")
# [NameEntity(start=8, end=18, text='Александру', kind='first', normal_form='Александр',
#             gender='m', case='datv', language='ru'), ...]
```

| Поле | Значение |
|---|---|
| `start`, `end` | позиции: `text[start:end] == entity.text` |
| `kind` | `"first"`, `"patronymic"`, `"surname"`, `"initials"`, `"nickname"` |
| `normal_form` | начальная форма: «Петровой» → «Петрова»; у ника — основной термин («Zik» → «Zik_2005») |
| `gender` | `"m"`, `"f"` или `"c"` (не определён; у ников всегда `"c"`) |
| `case` | `"nomn"`, `"gent"`, `"datv"`, `"accs"`, `"ablt"`, `"loct"`; у инициалов и ников `None` |
| `language` | `"ru"` или `"en"`; у ника — код динамической локали (`"tg"`, `"nick"`) |

## Класс `Anonymizer`

Принимает те же параметры и `consistent`. С `consistent=True` одно имя получает одну замену во всех вызовах — удобно для документа, чата или датасета, обрабатываемого по частям:

```python
from ru_name_anonymizer import Anonymizer

anon = Anonymizer(consistent=True)
anon.anonymize("Иван пришёл.")   # 'Леонид пришёл.'
anon.anonymize("Ивана нет.")     # 'Леонида нет.'
anon.reset()                     # забыть накопленные замены

state = anon.export_state()      # JSON-совместимый dict
Anonymizer(consistent=True).load_state(state)   # заменяет состояние, а не дополняет
```

Состояние (версия 2) включает и словарь ников с их заменами; состояния версии 1 тоже загружаются. `reset()` забывает замены, но не словарь ников.

`anonymize_detailed(text)` возвращает `AnonymizeResult(text, replacements)` — пары «сущность → подстановка» для аудита или обратного восстановления. Есть также `find(text)`, `preload()` и свойства `languages`, `kinds`, `aggressive`, `consistent`.

## Быстродействие и ресурсы

Замеры на текстах с высокой плотностью имён (66 тыс. символов, CPython 3.14, обычный ПК):

| Операция | Время |
|---|---|
| `import ru_name_anonymizer` | ≈60 мс (словарь ещё не загружен) |
| Загрузка словаря (первый вызов или `preload()`) | ≈0,2 с, ≈6 МБ памяти |
| `find_names` | ≈25 мс |
| `anonymize_names` / `anonymize_names_consistent` | ≈35–55 мс |
| `aggressive=True` | ≈70 мс |

- **Холодный старт.** Словарь (≈0,3 МБ на диске) грузится лениво. В сервисе вызовите `preload()` при старте, чтобы первый запрос не ждал.
- **Только нужное.** Без `"first"` в `kinds` или без `"ru"` в `languages` русский словарь не загружается вовсе; локали импортируются только при первом обращении.
- **Ники.** Все термины динамических локалей собираются в одно регулярное выражение, которое пересобирается только после `add_terms`/`remove_terms`. Без `dynamic` и `auto_detect` этого прохода нет вовсе. С `kinds="nickname"` статический разбор не запускается.
- **Один проход.** Текст разбирается одним регулярным выражением, результаты разбора слов кэшируются, поэтому время растёт линейно с длиной текста.
- **Потоки.** Один `Anonymizer` можно вызывать из нескольких потоков: в `consistent` вызовы идут по очереди под блокировкой, без `consistent` общего состояния нет. Для параллельной обработки большого корпуса удобнее процессы с общей таблицей замен через `export_state()`/`load_state()`.
- **Память в `consistent`.** Таблица замен растёт с числом разных имён (≈90 байт JSON на имя). Для независимых документов вызывайте `reset()`.
- **Большие объёмы.** Стандартных замен по 30 на род; когда их не хватает, `consistent` берёт замены из всего словаря (≈7,7 тыс. мужских, ≈4,8 тыс. женских имён и производные отчества и фамилии), так что разные имена не сливаются. Такие запасные имена бывают редкими («Зигмунт»). У своих `pools` и английских пулов (≈37 имён на род, 50 фамилий) запаса нет: при исчерпании будет `RuntimeWarning` и повторы.

## Как это работает

- **Имена** — по словарю ≈12,5 тыс. лемм. Падежи строятся правилами, нерегулярные формы («Павел» → «Павла») хранятся явно. Слова, которые чаще бывают обычными («Вера», «Мир», «Март»), в словарь не входят.
- **Отчества** — по суффиксам `-ович/-евич/-овна/-евна` в любом падеже.
- **Фамилии** на `-ов/-ев/-ин/-ын/-ский/-цкий` заменяются только рядом с именем, отчеством или инициалами (прилагательные вроде «Российский» отсеиваются).
- Понимаются инициалы («Иванов И.И.», «А.С.Пушкин»), имена через дефис («Жан-Люк»), омонимы с заглавной буквы («Света»). Имена, уже встреченные в тексте, не выбираются в качестве замены.
- Формы одного имени («Дмитрий» и «Дима») считаются разными людьми.

## Динамические локали: ники

Статические локали (`ru`, `en`) знают язык и сами ищут любые имена в тексте. Динамические знают только правила для идентификаторов, которые **передаёт приложение**: ники, username, подписи. Библиотека не пытается найти всех пользователей сама: что скрыть, решает приложение, а библиотека находит эти строки и заменяет их.

| | Статические (`ru`, `en`) | Динамические (`tg`, `nick`) |
|---|---|---|
| Что ищут | любые имена, отчества, фамилии | только переданные термины |
| Данные | словарь в пакете | `dynamic=` и `add_terms()` во время работы |
| Поиск | разбор слов, падеж, род | точное совпадение строки |
| Замена | имя в том же падеже | ник из пула: `суперслон2009`, `DiamondPotato2007` |

Типичный сценарий — бот в Telegram: он знает username и имя отправителя из метаданных и сообщает их до обработки текста.

```python
from ru_name_anonymizer import Anonymizer

anon = Anonymizer(dynamic={"tg": ["HACER777BEBRA"]})
anon.anonymize("HACER777BEBRA, ты сегодня прекрасен! Спасибо HACER777BEBRA'у, @hacer777bebra")
# 'NoobSlayer2014, ты сегодня прекрасен! Спасибо NoobSlayer2014'у, @NoobSlayer2014'

# во время работы: username и имя, которым человека называют в тексте, — одна группа
anon.add_terms("tg", user.username, aliases=[user.first_name])     # "Zik_2005", ["Zik"]
anon.anonymize("Zik wants more. Zik's request")
# 'TntGrandma2006 wants more. TntGrandma2006's request'

anon.add_terms("nick", {"Бебрыч": "кабачок2008"})   # своя замена
anon.remove_terms("tg", ["Zik_2005"])              # термин вместе с алиасами (или один алиас)
anon.terms()                                       # {"tg": {"HACER777BEBRA": []}, "nick": {"Бебрыч": []}}
```

- **Встроенные локали.** `tg` — базовый шаблон для Telegram: username из 5–32 символов `[A-Za-z0-9_]` (`@` в начале можно передавать), замена — английский ник, тоже допустимый username. `nick` — любые строки от 2 символов: кириллические заменяются русскими никами, остальные английскими. Ник в нижнем регистре получает замену в нижнем регистре.
- **Формат `dynamic`.** `{код: термины}`, где термины — строка, список или словарь `{термин: замена | None | {"aliases": [...], "replacement": "..."}}`. В `add_terms` то же самое, а для одного термина ещё `aliases=` и `replacement=`. Повторное добавление термина дописывает алиасы. Строка, уже принадлежащая другому термину, — `ValueError`: одна строка — один человек. Пачка терминов добавляется целиком или никак.
- **Регистр.** Термин ищется без учёта регистра. Алиас — как записан, с заглавной буквы и КАПСОМ, но не строчными: «Zik», «ZIK», но не «zik» (с `aggressive="any_case"` — в любом регистре).
- **Границы.** Термин не находится внутри другого слова («Zik» в «Zikov», «HACER777BEBRA» в «HACER777BEBRA2»), а окончания и `@` остаются на месте: «Zik's», «HACER777BEBRA'у», «@hacer777bebra».
- **Одна замена.** Термин и все его алиасы всегда получают одну замену в пределах объекта, даже без `consistent`. Разные термины — разные замены; когда сочетаний основы и года не хватает, добавляется суффикс.
- **Только ники.** `kinds="nickname"` заменяет только переданные термины и не трогает обычные имена в тексте. Удобно, например, для логов запросов к LLM, где встречаются персонажи историй.
- **Вместе со статическими.** Термины ищутся первыми, находки статических локалей внутри них отбрасываются. Если `"Дима"` добавлен в `nick`, «Дима» станет ником, а «Диме» заменит русская локаль. `exclude` и `replace` работают и для ников (`entity.kind == "nickname"`).
- **Автопоиск.** `Anonymizer(auto_detect=True)` (или `auto_detect="tg"`) перед заменой ищет `@упоминания` и добавляет их в словарь, после чего ник заменяется и без `@`. По умолчанию выключен; `find()` словарь не меняет. Адреса почты (`a@gmail.com`) не считаются упоминаниями.
- **Логи в JSON.** Обезличивайте строки до `json.dumps` или пишите с `ensure_ascii=False`: в экранированном виде (`З…`) кириллические ники не находятся.

Своя локаль — подкласс `DynamicLocale`. Переопределять можно `prepare` (привести термин к виду для поиска), `validate`/`validate_alias`, `word_chars` (что считать продолжением термина), `detect` (регулярка автопоиска, термин — группа `term`), `pool` и `fake` (замена):

```python
from ru_name_anonymizer import Anonymizer, DynamicLocale, register_dynamic_locale

class DiscordLocale(DynamicLocale):
    code = "discord"
    detect = r"(?<!\w)@(?P<term>[a-z0-9_.]{2,32})"

    def fake(self, term, rng, used):
        return f"user{len(used) + 1}"

register_dynamic_locale(DiscordLocale())
Anonymizer(auto_detect="discord").anonymize("@neo_42 привет, neo_42")
# '@user1 привет, user1'
```

## Свой язык

Всё, что зависит от языка, лежит в `src/ru_name_anonymizer/locales/<код>/`: алфавит, словарь, правила распознавания отчеств и фамилий, склонение и списки замен. Ядро (`anonymizer.py`) общее: находит слова, группирует «имя + отчество + фамилия», подбирает замены и следит за согласованностью.

```
locales/
  base.py          # класс Locale — интерфейс локали
  ru/              # __init__.py (RussianLocale), dictionary.py, morphology.py, pools.py, names.txt
  en/              # __init__.py (EnglishLocale), names.py
```

Новый язык — это подкласс `Locale`. Обязательно задать `code`, буквы `upper`/`lower` (содержимое класса символов регулярного выражения), `classify_word` и `default_pools`. Остальное необязательно и по умолчанию означает «не склоняется»: `decline`, `inflect`, `normal_form` (склонение), `surname_categories`/`custom_pools` (свои категории замен), `fallback_pool` (запас для больших объёмов), `is_common_name`/`is_common_word` (омонимы), `preload`.

```python
from ru_name_anonymizer import Locale, anonymize_names, register_locale
from ru_name_anonymizer.locales import titled

class BelarusianLocale(Locale):
    code = "be"
    upper = "А-ЗЙ-ПР-ШЫЬЭЮЯЁІЎ"
    lower = "а-зй-пр-шыьэюяёіў'"
    NAMES = {"Алесь": "m", "Васіль": "m", "Алеся": "f"}

    def classify_word(self, token, opts):
        if "first" in opts.enabled and token in self.NAMES:
            return "first", (token, self.NAMES[token], "nomn")
        if "surn" in opts.enabled and titled(token) and token.endswith(("ук", "ёнак")):
            return "surn", (token, "c", "nomn")
        return None, None

    def default_pools(self):
        return {"first:m": ["Міхась", "Сымон"], "first:f": ["Ганна", "Ядвіся"], "surn": ["Ткачук", "Мельнік"]}

register_locale(BelarusianLocale())
anonymize_names("Васіль Ткачук", languages=("be", "ru"))
```

Чтобы язык стал встроенным, положите такой класс в `locales/be/__init__.py` с `LOCALE = BelarusianLocale()`: пакет найдётся сам, `register_locale` не нужен. Файлы данных (`*.txt`) в папке локали попадают в сборку автоматически. Свои замены для конкретного языка: `pools={"be:first_m": [...]}`.

## Ограничения

- По умолчанию заменяются только слова с заглавной буквы; омонимы и одиночные фамилии — только с `aggressive`.
- Английские фамилии-слова («White», «Green») без имени рядом не заменяются даже в `aggressive`.
- `exclude` работает по отдельным словам: фразу «Петров и партнёры» целиком не исключить.
- Ники не склоняются: «HACER777BEBRA'у» заменится, а транслитерация вроде «Хасеру» — нет. Нужные написания добавляйте алиасами.
- Это инструмент для debug-логов и тестовых данных, а не гарантия полной обезличенности.
